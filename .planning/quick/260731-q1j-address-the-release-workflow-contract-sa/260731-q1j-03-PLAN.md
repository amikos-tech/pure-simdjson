<interfaces>
From `library_loading.go`:
- `activeLibrary()` already releases `libraryMu` before path resolution, bootstrap, dlopen, and binding; it must be called with no kernel-state mutex held.

From `kernel.go`:
- `SetKernel` currently holds `kernelMu` across `SetImplementation`; a reservation protocol must make it wait before this point, then re-check `kernelSelectionLocked` after a utility completes.
- `markKernelSelectionAfterUtility(rc)` is the final state transition and must exclude exactly CPUUnsupported, BufferTooSmall, and InvalidArg.

From `materializer_fastpath.go`:
- `runtime.KeepAlive(doc)` must stay ordered before `doc.mu.Unlock()` so the borrowed native frame span remains readable until all strings are copied.
</interfaces>
