<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| C++ parser -> `noexcept` native bridge -> Rust | Untrusted input or resource exhaustion can make C++ throw; no exception or termination may cross this boundary. |
| First allocation failure -> diagnostic capture | The handler is already under memory pressure, so any unguarded diagnostic allocation can become a second exception and trigger `std::terminate`. |
| Failed native call -> output location | An error path must not publish a partial or mutated output value that Rust could mistake for valid state. |
| Hidden test seam -> public ABI | Deterministic fault injection is test-only and must not become a public symbol, header declaration, Go binding, or production control. |
| Child test process -> parent verdict | A subprocess is required so an abort or `std::terminate` becomes observable evidence instead of killing the whole test runner. |
