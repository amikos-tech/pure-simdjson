<objective>
Close the large-depth diagnostic replay crash by making depth 1024 the single supported ceiling across every parser-owned traversal.

Purpose: The immutable v0.1.7 behavior accepted caller-controlled depths far beyond the native call stack, so malformed input could terminate the process before DIAG-02 returned known/unknown state. D-13 already requires unsafe positive values to fail instead of being clamped; this plan applies that rule consistently at the Go and native boundaries.
Output: one enforced depth contract, a signal-isolated maximum-depth regression, generated public contract updates, and refreshed source-gate evidence.
</objective>
